# Source-media publication decisions

Checked 24 October 2026. The user authorised publishing source evidence that is
open for redistribution. Public access to a scan is not evidence of an open licence.

| Material | Finding | Repository treatment |
|---|---|---|
| NIVAL archive images, including JPEG and JP2 downloads | No open redistribution licence established. NIVAL's reproduction policy requires requests for public-facing reproduction and notes that it usually does not own the underlying copyright. | Catalogue links, factual identifiers, dimensions, hashes and coordinates; no newly downloaded scans or scan-containing overlays |
| Bolger thesis volumes at RCA | Repository policy allows certain personal, educational and non-profit copying; the examined record does not establish an unrestricted open licence, including for reproduced third-party images. | Links, bibliographic facts, page/figure references and hashes; no mirrored PDFs or embedded images |
| NCAD theses, museum and Heritage Council PDFs | No open redistribution licence verified during this pass. This records an evidence gap, not a conclusion that every use is forbidden. | Links and factual research metadata |
| Modern revival specimens | Excluded from design references by the user's direction; no need to mirror | Bibliographic links only, explicitly marked as context |
| New research font software, trace data, scripts and analysis | Created for this repository; source-media permissions are not transferred to the new files | Included with the repository's existing font-software licence; candidate includes OFL.txt |

Policies: [NIVAL reproduction policy](https://www.nival.ie/resources/reproduction-policy/),
[RCA repository policy](https://researchonline.rca.ac.uk/policies.html).
These links document the publication decision; this is not a claim of a licence
grant from the historical designers or archives.

Keep retrieved media and generated source-image comparisons under ignored `build/`.
The committed `text-proof.png` contains only text rendered from the new candidate,
not archival image pixels. The local illustrated review and research ZIP contain
external images and are not part of this commit.

This pass does not remove or retrospectively clear source images already present
in the baseline repository. Before adding any further external media, record the
specific licence or permission, scope, attribution and evidence URL. A website being
reachable, or an image being old, is insufficient to mark it openly redistributable.
