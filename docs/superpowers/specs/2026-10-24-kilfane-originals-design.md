# Kilfane: first original-source iteration

The user wants faithful reconstruction from original material, one face at a time, with extra effort on evidence and repeated visual inspection. Modern revivals are excluded as design references. Start with Kilfane because several original specimens are available. This ordering is the assistant's implementation choice.

## Approach
Use multiple original specimens to test and improve the existing regular outlines. A blind retrace of one larger image would reproduce its damage; subjective redrawing would lose provenance. Preserve the released font, generate a separate research candidate, and compare every attested glyph against additional specimens while investigating their independence. N516 and N47 were subsequently found to share reproduction history. Do not describe a candidate as an authenticated original or claim ultimate quality from a similarity score.

## Scope
Inspect NIVAL 46 (production flyer), 47 (large paired specimen), 516 (Kilfane alphabet) and 517 (sheet photographs). Register images without independent per-glyph horizontal/vertical distortion. Record source coordinates, scale and uncertainty. Reuse the existing Python pipeline and alternate names provisionally; preserve current original/modern-extension distinctions. Begin with attested letters and figures, retaining uncertain marks until supported. Produce installable regular OTF/TTF/WOFF2 candidates and an illustrated comparison with the previous release. Do not publish or overwrite the release.

## Publication update
After the local iteration, the user authorised pushing research and openly redistributable source evidence to the repository. The candidate remains separate from the release. External media without an established open redistribution licence are represented by source links, hashes, coordinates and retrieval notes; see research/RIGHTS.md.

## Acceptance
Every proposed glyph has inspectable evidence. No unrecorded changes to other faces. Source transforms preserve relative proportions. Closed contours, counters, shaping and output fonts pass meaningful checks. Report improvements, regressions, uncertainty and uncompleted work honestly. Existing styles/extensions are not the historical target of this pass.
